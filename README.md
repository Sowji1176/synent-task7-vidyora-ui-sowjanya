# VIDYORA — Educational Platform UI

VIDYORA is a fictional modern learning platform UI created for Task 7: UI Design (Website or App).

## Project Overview

A professional responsive educational website built using HTML5, CSS3, and JavaScript.

## Main Sections

- Home / Hero
- Courses / Learning Paths
- Explore / Why VIDYORA
- About VIDYORA
- Testimonials
- Pricing
- FAQ
- Contact / Final CTA
- Footer

## Features

- Responsive desktop and mobile design
- Interactive navigation
- Mobile hamburger menu
- Smooth scrolling
- Active navigation states
- Course category filtering
- Course exploration modal
- Animated statistics
- Scroll-reveal animations
- Testimonial slider
- FAQ accordion
- Pricing interactions
- Contact links
- Back-to-top button
- Preloader animation
